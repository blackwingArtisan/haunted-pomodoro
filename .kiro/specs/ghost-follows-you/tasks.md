# Tasks: The ghost follows you

A task is checked only when code and a test implement it. Nothing here is built yet: this spec was written first, and the two sessions below are the plan for building it. A test names the criteria it checks with this spec's folder name in front, for example `// Req ghost-follows-you:2.3, 2.4`, until task 11 makes the trace script read every spec.

Numbers in `(Req …)` are criteria of `requirements.md` in this folder.
